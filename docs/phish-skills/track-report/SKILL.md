# 追踪报告(线四)
[read-only] /opt/tools/bin/phish-track.py report

## 漏斗指标
- 发送量 → 送达率 → 打开率 → 点击率 → 提交率
- 按部门/角色/时间分组
- 与行业基准对比(钓鱼测试平均打开率 20-30%)

## 蓝队检测覆盖度
- 邮件网关是否拦截(比率)
- 着陆页是否被标记
- 凭据提交后是否有告警

## 报告产出
campaign 效果 + 薄弱环节(哪些部门/角色最易中招) + 建议培训重点
