# 追踪报告(线四) v2
[read-only] phish-track.py report + proxy 事件合并

## 漏斗指标
- 发送 → 送达 → 打开 → 点击 → 提交
- 按部门/角色/时间切片
- 行业基准:打开 20-30% / 点击 5-10% / 提交 2-5%

## 检测覆盖度(蓝队视角)
- 邮件网关拦截率(送达 vs 发送差值)
- 着陆页是否被安全浏览器标记
- 凭据提交后是否有告警(SSO 风控)
- 端点检测(附件载荷是否被 EDR 拦)

## 报告产出
- campaign 时间线 + 漏斗图
- 薄弱部门/角色排序
- 与上次 campaign 对比(培训效果)
- 建议:哪些部门需要安全意识培训
