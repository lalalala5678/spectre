# 弱口令检测方法

## 1. 登录面侦察(先于一切尝试)
- 错误次数策略:同一账号故意错 N 次(N=3,5,10 阶梯),观察响应差异
  (锁死提示?验证码强制?)→ 确定安全尝试配额,永不超
- 验证码:次数阈值前是否免验证码;强制后停止该面
- 响应差异:错误密码 vs 错误账号的报文差异(可枚举用户名?)
- 协议:query_intel 优先(上游可能已还原加密协议);否则抓登录 JS 自行还原

## 2. 目标选择(优先级)
1. 默认/出厂口令(厂商名+123/年份组合)——命中率最高且零锁风险
2. 模式口令:账号名+后缀(123456/@123/666/888/QQ);学号工号体系直接试
3. top500 弱口令(配额内)

## 3. 加密登录实现
```bash
python3 -m venv /tmp/wc && /tmp/wc/bin/pip install pycryptodome -q
# AES-128-CBC(金智 CAS):random64 前缀+salt 派生,参考情报库协议描述
```

## 4. 节流与证据
- 每账号 ≥3s 间隔;单面并发 ≤2;拿到成功立即停全账号
- 证据:登录成功响应片段(用户名回显/session cookie 截断)
- 落账:report_vulnerability(核心系统可登录=高危;PII 系统=critical 候选)
  + publish_intel(凭据给 nday/api 下游,注明仅限授权测试)
