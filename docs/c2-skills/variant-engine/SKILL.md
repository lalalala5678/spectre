# 变体引擎(线二,/opt/tools/bin/c2-variant.py)
公开 BypassAV 图谱内的技术分层组装,不发明新原语。

## 变换族
1. 标识符/字符串随机(类名/方法名/常量/错误文案)
2. 加密层轮换:XOR 多密钥/AES-GCM/RC4(轮换而非新增)
3. 编码层:base64 变体(hex/uuid/分割/自定义字母表)
4. 结构变换:执行序打乱/垃圾基本块/延迟绑定/异常流隐藏
5. 资源形态:资源段/.data 段/分离文件/注册表残留
## 策略选择
按检测报告特征名反查变换族(如 clamav 报 Win.Trojan.xxx=行为特征→
结构变换;YARA 字符串命中→加密层+编码层);同族变体不连续重试,
两轮同类未过=换族。
## 指纹
每变体记录(sha256,变换族组合,轮次),交付包含指纹清单。
